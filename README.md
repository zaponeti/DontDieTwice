# DieHardPractice

Пустой шаблон мода для Minecraft на Fabric.

- Minecraft: 1.21.1
- Fabric Loader: 0.20.1+
- Java: 21

## Сборка

```
./gradlew build
```

## Запуск клиента в режиме разработки

```
./gradlew runClient
```

## Запуск сервера в режиме разработки

```
./gradlew runServer
```

Собранный мод появится в `build/libs/`.
